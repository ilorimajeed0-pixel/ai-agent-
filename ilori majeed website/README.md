# Ilori Majeed — Website

Plain HTML, CSS and JavaScript. No build step.
To preview: double-click `index.html`. A local server is not currently installed.

## Files

- `index.html` — the complete one-page website.
- `css/style.css` — design tokens, responsive layout and animations.
- `js/main.js` — isolated interactive features and form handling.
- `assets/img/` — current website images.
- `LAUNCH-CHECKLIST.md` — information required before public deployment.
- `vercel.json` — static hosting and security-header configuration.
